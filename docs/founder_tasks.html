Week 1: Go live

  1. 5 min

    Your confidentiality answer for NDA partners. Recommended: Render, Frankfurt (EU).

    Click by click
    1. Choose Render, Frankfurt (EU) (simplest, used in the steps below), or a VPS in Israel/EU if you want full control.
    2. Write down the sentence you will show staff and partners, e.g. Render, Frankfurt EU. You type it in task 3 as HOSTING_LOCATION; the app shows it under Settings (הגדרות) → Data & privacy (נתונים ופרטיות).
  2. 10 min

    With a company email, two-factor login, and a payment card (the data disk needs a paid service, about $7–8 a month).

    Click by click
    1. Go to render.com → Get Started.
    2. Click GitHub and sign in with the GitHub account that owns amitaimyers/ymt (this lets Render see the code). Use the company email when Render asks for one.
    3. Top-right avatar → Account Settings → Security → turn on Two-factor authentication and scan the code with an authenticator app.
    4. Top-right workspace menu → Settings → Billing → Add payment method → enter the company card → Save.
  3. Persistent disk required15 min

    One web service, built from the repository's Dockerfile, with a 1 GB disk for the database.

    Click by click
    1. Render dashboard → + New (top right) → Web Service.
    2. Under Git Provider, pick amitaimyers/ymt. Not in the list? Click Configure account / Connect GitHub, allow access to the ymt repository, come back and pick it.
    3. Fill in the form:
      • Name: ymt-app (this becomes the address ymt-app.onrender.com)
      • Language: Docker (Render detects it from the Dockerfile)
      • Branch: claude/ymt-group-pwa-mvp-45memd
      • Region: Frankfurt (EU Central)
      • Instance Type: Starter (not Free: Free has no disk and no shell)
    4. Environment Variables → Add Environment Variable → Key HOSTING_LOCATION, Value Render, Frankfurt EU.
    5. Open Advanced → Add Disk → Name ymt-data, Mount Path /data, Size 1 GB.
    6. Still under Advanced: Health Check Path /api/health; Auto-Deploy On (every new version of the code goes live by itself).
    7. Click Deploy Web Service. Wait 3–6 minutes until the status at the top says Live (the Logs end with YMT server listening).

    Without the disk at /data, every restart deletes all data.

  4. This is your app URL5–20 min

    The address everyone opens and installs.

    Click by click
    1. Render → your service ymt-app. The address is shown at the top under the name, e.g. https://ymt-app.onrender.com. Click the copy icon next to it and save it in a note.
    2. Open it: you should see the YMT sign-in page.
    3. Optional, own domain: service → Settings → Custom Domains → + Add Custom Domain → type e.g. app.ymt-group.com → Save. Render shows a CNAME record.
    4. At your domain provider (e.g. GoDaddy, Cloudflare, Box): DNS settings → add record → Type CNAME, Name app, Value ymt-app.onrender.com → save.
    5. Back in Render → Verify. When it shows Certificate Issued, https://app.ymt-group.com works.
  5. 5 min

    The first account is created once, from Render's shell. Everyone else is added in the app (task 7).

    Click by click
    1. Render → service ymt-app → left menu Shell. Wait for the prompt.
    2. Copy this command, paste it in the shell, replace the three values in <…> (password: at least 10 characters), press Enter:
      node server/scripts/create-user.js --username <you> --name "<your name>" --password "<10+ characters>" --admin
    3. It answers that the user was created. Open your app address and sign in with that username and password.
  6. 5 min

    Opens like an app from the home screen or dock.

    Click by click
    1. Computer (Chrome or Edge): open the address → sign in → Settings (הגדרות) → General (כללי) → in the Appearance (תצוגה) card, section App (אפליקציה) → Install app (התקנת האפליקציה) → Install.
    2. Android (Chrome): same steps; the app icon appears on the home screen.
    3. iPhone / iPad (Safari): open the address in Safari → the Share icon (square with an arrow) → Add to Home Screen → Add.

    2. Settings → Billing → Buy credits → e.g. $25 → pay with the company card.
    3. Settings → Spend limits (direct link) → next to Monthly spend limit click Set limit (or Adjust limit) → 25 → save.

    6. In the app: Mandates (מנדטים) → card AI settings (הגדרות AI) → Monthly AI cap (USD) (תקרת AI חודשית (USD)) = 20 → Save (שמירה).
    7. For each mandate (SH1, SH2, SH3, OM1, OM2, OM3, GE1): click its code → card Mandate settings (הגדרות המנדט) → Owner (בעלים): choose the person → Status (סטטוס): Active (פעיל) → optionally Schedule (תזמון): Weekly (שבועי) and a weekday → Save (שמירה).

  3. 45 min

Optional: Google Calendar and Gmail replies

Skip this section if you don't need meetings in Google Calendar or automatic reading of email replies. Replies can always be pasted into a conversation.

  1. 30 min

    A Google Cloud project with the Calendar API, a sign-in client for YMT, and four values on Render.

    Click by click
    1. Go to console.cloud.google.com with the company Google account → project picker at the top → New Project → name YMT App → Create → select the new project.
    2. Menu ☰ → APIs & Services → Library → search Google Calendar API → Enable.
    3. Menu ☰ → Google Auth Platform (older screens: OAuth consent screen) → Get started:
      • App name YMT Group, User support email: yours → Next
      • Audience: Internal if YMT uses Google Workspace; otherwise External → Next
      • Contact information: your email → Next → tick the agreement → Create
    4. External only: Audience → Publish app → Confirm (otherwise connections stop after 7 days).
    5. Clients → Create client → Application type: Web application → name YMT Render → Authorized redirect URIs → + Add URI → https://<your app address>/api/google/callback (from task 4) → Create.
    6. A window shows the Client ID and Client secret: copy both into a note (or Download JSON).
    7. Render → service → Environment → add four variables:
      • GOOGLE_CLIENT_ID = the Client ID
      • GOOGLE_CLIENT_SECRET = the Client secret
      • PUBLIC_URL = your app address, e.g. https://ymt-app.onrender.com (no / at the end)
      • TOKEN_ENCRYPTION_KEY = click Generate next to the value field. Never change it later (it would disconnect everyone).
      → Save, rebuild, and deploy.
    8. In the app, each person: Calendar (יומן) → Connect Google Calendar (חיבור Google Calendar) → choose the Google account → Allow.
  2. 15 min

    Read-only: only messages from people YMT wrote to. Needs task 6b first.

    Click by click
    1. Google Cloud (same project) → ☰ → APIs & Services → Library → search Gmail API → Enable.
    2. ☰ → Google Auth Platform → Data Access → Add or remove scopes → filter gmail.readonly → tick it → Update → Save.
    3. Audience Internal (Google Workspace): done. Audience External (personal Gmail): Google requires a security review for this permission before people outside the test users can connect; until then add each owner under Audience → Test users → + Add users, or simply paste replies.
    4. In the app, each owner: Conversations (שיחות) → Connect Gmail to read replies (חיבור Gmail לקריאת תשובות) → choose the account → Allow. The app checks every 15 minutes; Check now (בדיקה עכשיו) runs it at once.

Appendix: get the code on your own computer

Not needed to run the app (Render builds it from GitHub). Useful to look at the code, run it locally, or keep your own copy. Windows commands; on a Mac use Terminal and a folder such as ~/code/YMT.

  1. First time
    Click by click
    1. Install Git for Windows and Node.js 22 (LTS) with the default options.
    2. Start menu → type PowerShell → open Windows PowerShell.
    3. Copy the commands below, paste them into PowerShell, press Enter (the first one may open a GitHub sign-in window: sign in with the account that owns the repository):
      git clone https://github.com/amitaimyers/ymt.git C:\code\YMT; cd C:\code\YMT; git checkout claude/ymt-group-pwa-mvp-45memd
    4. Run it locally with fictional demo data (opens on http://localhost:5173, sign in as admin / change-me-123):
      npm install; npm run user:create -- --username admin --name "Admin" --password "change-me-123" --admin; npm run seed:demo; npm run dev
    5. Stop it with Ctrl+C in PowerShell.
  2. Every time later (get the newest version)
    Click by click
    1. Open PowerShell and run:
      cd C:\code\YMT; git checkout claude/ymt-group-pwa-mvp-45memd; git pull; npm install
    2. Then npm run dev as before. Your local demo data stays in C:\code\YMT\data and is separate from the live app.

Decisions to make (no rush)

  • Signatures: the built-in e-signature is a simple electronic signature. If a contract needs a qualified signature under Israeli law, use a certified signing provider for that contract.
  • Sending email: today you send each approved message from your own mailbox, LinkedIn or WhatsApp and click "mark as sent". Decide later whether you want a per-message Send button in the app (it would still require approval).
  • Updates: with Auto-Deploy on (task 3), every new version of the code goes live by itself after a few minutes. To deploy by hand: Render → service → Manual Deploy → Deploy latest commit.
