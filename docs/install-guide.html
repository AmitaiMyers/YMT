Install the YMT CRM on a new computer

About 15 minutes. Windows commands are shown (PowerShell); on a Mac use Terminal – the commands are the same.

  1. Install Node.js 22 and Git

    Node.js: nodejs.org → download 22.x LTS → install with the defaults.

    Git: git-scm.com/downloads → install with the defaults.

    Close and reopen PowerShell, then check:

    node -v
git --version

    node -v must show v22.13 or newer.

  2. Download the code

    mkdir C:\code
cd C:\code
git clone https://github.com/AmitaiMyers/YMT.git ymt
cd ymt
git checkout claude/ymt-group-pwa-mvp-45memd

    The repository is private: sign in with a GitHub account that has access when Git asks.

  3. Install the app's packages

    npm install

  4. Create the settings file

    copy .env.example .env
notepad .env

    To use the AI agents, add your Claude API key as a new line, then save:

    ANTHROPIC_API_KEY=sk-ant-...

    Never share this file; it is not uploaded to GitHub.

  5. Create your admin user

    npm run user:create -- --username amitai --name "Amitai" --password "choose-10-plus-chars" --admin

    Optional – sample data to try things out: npm run seed:demo

  6. Start the CRM

    npm run dev

    Open http://localhost:5173 and sign in. Keep the PowerShell window open while you work; Ctrl+C stops the app.

Every day after that

cd C:\code\ymt
npm run dev

Get the latest version

cd C:\code\ymt
git pull origin claude/ymt-group-pwa-mvp-45memd
npm install
npm run dev

If something goes wrong

  • "engine" or "Unsupported engine" error – Node.js is older than 22.13. Install Node 22 (step 1) and run npm install again.
  • "'npm' / 'git' is not recognized" – close and reopen PowerShell after installing.
  • "address already in use" – the CRM is already running in another window; use that one or close it.
  • The page doesn't change after an update – press Ctrl+F5.

Your data stays on this computer, in C:\code\ymt\data. Back up that folder.
